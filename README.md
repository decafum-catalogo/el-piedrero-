# El Piedrero

Juego de supervivencia urbana en 3D para el navegador, ambientado en La Carpio, San José, Costa Rica (Garabito, Avenida 49 y Calle 54). Uso personal.

## Cómo correrlo

```bash
npm install
npm run dev      # abre la dirección que muestra la terminal
npm test         # pruebas
npm run build    # versión de producción
```

## Qué trae

- Barrio de La Carpio: calles y avenidas, casas de zinc y concreto, parque, cancha, lote baldío, gasolinera y quebrada.
- Personajes con nombre: Rubén (advierte de peligros), Licho (tonteras), Celso (la vuelta de la noche), El Cliente y El Chupacabras Cochón (compra latas, chatarra y cobre).
- Misión nocturna de Celso (10 pm a 5 am): llevar la bolsita al parque sin que la vea la Fuerza Pública. Recompensa: ₡2.000 y un purito.
- Peligros: perros callejeros bravos, chapulines de noche y zonas a evitar.
- Reloj digital de pulsera, colones (₡), reciclaje, pelar cables, inventario, pulpería y el chante.
- Ciclo de día y noche, necesidades de supervivencia, radio AM/FM y El Chato.
